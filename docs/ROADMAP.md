# Roadmap

## ✅ Done (v1.0 MVP)
- [x] Multi-source job scraping (Remotive, RemoteOK, Arbeitnow)
- [x] CV upload & PDF parsing
- [x] CV editor with Markdown
- [x] AI CV adaptation per job
- [x] AI cover letter generation (3 templates)
- [x] Apply flow with CV personalization + cover letter
- [x] Kanban pipeline (drag & drop)
- [x] SQLite persistence for all data
- [x] Tauri desktop app (.app bundle)
- [x] Dashboard with stats

- [ ] Email notifications for application status changes
- [ ] More job sources (We Work Remotely, AngelList, etc.)

- [ ] Multiple user profiles
- [ ] CV PDF export/generation
- [ ] Application deadline reminders
- [ ] Browser extension for one-click save
